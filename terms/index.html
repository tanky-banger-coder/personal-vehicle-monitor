Hermes CB8 – Terms and privacy

Effective date: 31 October 2026

Purpose and availability

Hermes CB8 is a private, non-commercial application operated by and solely for the vehicle owner. It is not offered to the public and carries no service-level commitment or warranty.

Data accessed

With the owner's explicit Volvo ID consent, the application may read vehicle identity and status, battery and charging information, odometer and trip statistics, diagnostics, warnings, and the latest vehicle location.

Read-only operation

The application requests read scopes only. It does not request vehicle commands such as locking, unlocking, starting climate control, starting the engine, flashing lights, or sounding the horn.

Use, storage, and sharing

Data is used only for the owner's personal vehicle and home-energy monitoring. It may be stored locally on systems controlled by the owner. Vehicle data is not sold, used for advertising, or shared with third parties except where technically necessary to operate Volvo Cars' APIs or where required by law.

Access and deletion

The owner may revoke the application's Volvo ID access at any time and may delete locally stored data and credentials.

Security

OAuth credentials and tokens are kept outside this public website. This site contains no vehicle data, API keys, client secrets, or access tokens.

Contact

Questions can be submitted through the repository hosting this page: GitHub issues.
